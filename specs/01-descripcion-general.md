# HOCICOS A.J. — Descripción general

## 1. Nombre del proyecto
HOCICOS A.J.

## 2. Descripción
Sistema web para gestionar la venta de ropa para perros.

## 3. Objetivo
Desarrollar una aplicación web que permita
administrar los productos, usuarios y compras
de HOCICOS A.J.

## 4. Tecnologías
- C#
- ASP.NET Core MVC
- .NET 10
- Entity Framework Core
- MySQL

## 5. Base de datos existente
La base original se llama `hocicos_aj` y contiene
las siguientes seis tablas. El desarrollo y las pruebas manuales deben apuntar
exclusivamente a la base aislada `hocicos_aj_test`; no se debe modificar la original:

- categoria
- usuarios
- productos
- compras
- detalle_compra
- comprobante

## 6. Restricciones
- Respetar la estructura de la base de datos existente.
- Definir las funcionalidades antes de implementarlas.
- Seguir la metodología Spec-Driven Development (SDD).
